# Descrição Geral
Cursed Dungeons é um jogo desenvolvido para a Nes Gamejam, inspirado principalmente no The Legend of Zelda de Nes, onde o jogador deve adentrar em uma masmorra, enfrentar criaturas, chegar no centro da dungeon e quebrar uma joia amaldiçoada.
